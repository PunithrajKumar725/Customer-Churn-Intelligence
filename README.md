
# Customer Churn Intelligence System

## 1. Project Overview

An end-to-end Data Science and Machine Learning
project designed to predict customer churn and
support customer retention decisions.

## 2. Problem Statement

Telecommunication companies face significant
challenges in retaining customers due to changing
customer preferences, pricing concerns and service
experiences.

This project aims to develop a Machine Learning
system that identifies customers who are likely
to discontinue their services by analyzing
customer demographics, subscription details,
contract types and billing information.

The system will predict customer churn risk and
provide data-driven retention suggestions to
support proactive business decisions.

## 3. Project Objectives

- Analyze customer behaviour.
- Identify factors associated with customer churn.
- Develop Machine Learning prediction models.
- Estimate customer churn probabilities.
- Categorize customers based on risk.
- Provide retention suggestions.
